# CozyNotes v0.1.1 release

Approved by the user on October 17, 2026.

Publish GitHub release `v0.1.1` from the current application, including the tray,
Settings, appearance, and bulk note selection work already on `main`.

## Downloads

- Windows x64: standalone `Cozynote.exe` and an NSIS setup executable.
- macOS: separate Apple Silicon and Intel DMGs. These are not signed with an
  Apple Developer ID or notarized; disclose this on the release page.
- Linux x64: AppImage and Debian package, built on Ubuntu 22.04.
- SHA-256 checksums for all six downloads.

## Publication

Keep npm, Cargo, lockfiles, and Tauri versions synchronized at `0.1.1`. A tag
workflow builds and tests the native targets, retains the packages as workflow
artifacts, and publishes only when all builds succeed. The Windows standalone
executable is built separately using Tauri's `--no-bundle` option.

Use the existing application identity and local note storage. Signing credentials,
automatic in-app updates, new application features, and data migrations are out of
scope. Native macOS/Linux interaction testing remains outstanding and must be
disclosed separately from successful packaging checks.

## Acceptance

The published GitHub release points at the verified `v0.1.1` tag and contains the
six expected nonempty binaries/packages and a checksum file. The release notes
identify each platform, architecture, and current signing/testing limitations.
