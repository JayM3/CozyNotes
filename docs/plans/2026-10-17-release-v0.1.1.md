## Verification strategy

The change concerns version metadata and release configuration. Validate the real
frontend/backend suites and real platform packages rather than add tests that
only repeat workflow text. All six expected downloads must exist before
publication. Compute SHA-256 hashes from the assembled packages. Do not claim
native macOS/Linux interaction testing based on CI build success.
