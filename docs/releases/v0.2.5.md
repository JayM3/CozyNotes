# CozyNotes v0.2.5

## Changelog

- Add editable ink drawings to notes from **More > Insert ink drawing**, or the pen button in wider notes. Draw with a Windows pen using pressure-sensitive strokes, four colors, and three widths, or enable **Draw with mouse**.
- Erase whole strokes, undo and redo drawing changes, and add an optional searchable description. Drawings stay editable after saving, duplicating a note, or restoring note history.
- Preserve an in-progress stroke when closing or folding a note or switching away. Touch contacts do not draw; handwriting recognition is not included.
- Drag the main menu window from its top heading and branding area.
- Prevent elastic overscroll from shifting note windows when scrolling past the ends of a note.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.5_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
