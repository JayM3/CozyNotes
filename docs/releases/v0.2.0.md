# CozyNotes v0.2.0

## Changelog

- Added Remember my desk, which reopens notes left open at exit with their sizes, positions, and folded state.
- Added favorites with starring from the library or note menu, favorite-first ordering, and a Favorites only filter.
- Added note history with read-only previews of earlier saved versions, including rich text and images.
- Added Restore as new note for historical versions, with independent copies of attached images.
- Added folded note windows that retain their expanded dimensions when unfolded.
- Improved checklist layout so long items wrap beside their checkbox.
- Added migration support for the new favorites, history, and desk persistence data while preserving existing notes.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.2.0_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS:** Open the matching `.dmg` file and drag CozyNotes to Applications. The builds are unsigned and not notarized, so macOS may require approval in Privacy & Security.
- **Linux x64:** Use `CozyNotes_0.2.0_linux_x64.deb` with your package manager, or make `CozyNotes_0.2.0_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Use `SHA256SUMS.txt` to verify downloaded files.
