# CozyNotes v0.2.10

## Hotfix

- Compact the note toolbar to reclaim writing space while keeping formatting and note actions accessible.
- Migrate notes using the previous default toolbar height to the new compact height. Custom toolbar heights remain intact.
- Add a title visibility control so notes can be written without the title field taking up space.
- Keep find and editor focus working when the note title is hidden.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.10_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
