# CozyNotes v0.2.8

## Hotfix

- Add an **Open on startup** setting that registers CozyNotes to launch when the Windows user signs in.
- Report the actual Windows startup registration state in Settings and keep the previous value when registration changes fail.
- Keep the existing Run in background and Remember my desk preferences synchronized after changes.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.8_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
