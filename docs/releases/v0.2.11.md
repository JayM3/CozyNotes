# CozyNotes v0.2.11

## Changes

- Add **New note defaults** in Settings: choose a paper color, Source Sans 3 or Nunito font, base text size, and a window-size preset or custom dimensions. Preview your choices before saving.
- Apply saved defaults to newly created blank notes. Existing notes retain their own appearance and remembered window size.
- Preserve source typography and expanded window dimensions when duplicating a note or restoring a history version as a new note. History previews display the recorded font and text size.
- Reset temporary reading-size adjustments to the note's saved base text size with Ctrl+0 or by reopening the note. Autosave preserves an active temporary adjustment.
- Use the current configured default dimensions when double-clicking a Windows note border or corner to reset its size.
- Migrate existing settings, notes, and history to support note defaults and typography while preserving content and window arrangements. Existing notes retain Source Sans 3 at 16 px.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.11_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
