# CozyNotes v0.2.3

## Changelog

- Added update checks in Settings with one-click installation and automatic restart after a downloaded update.
- Added signed Tauri updater artifacts for Windows x64, macOS Apple Silicon, macOS Intel, and Linux x64.
- Added an in-app Source code link to the CozyNotes repository.
- Improved update status, error, and installation feedback in Settings.
- Refined the library selection action styling so moving active notes to Trash is visually distinct from permanent deletion.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.2.3_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS Apple Silicon:** Open `CozyNotes_0.2.3_macos_aarch64.dmg` and drag CozyNotes to Applications.
- **macOS Intel:** Open `CozyNotes_0.2.3_macos_x64.dmg` and drag CozyNotes to Applications.
- **Linux x64:** Use `CozyNotes_0.2.3_linux_x64.deb` with your package manager, or make `CozyNotes_0.2.3_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

The application can check for later releases from Settings. Signed updater packages and their signatures are included for supported architectures. Windows and macOS builds are unsigned, and macOS builds are not notarized. macOS may require approval in Privacy & Security.

Use `SHA256SUMS.txt` to verify downloaded files.
