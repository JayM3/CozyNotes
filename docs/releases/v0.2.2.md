# CozyNotes v0.2.2

## Changelog

- Added Windows note snapping to desktop work-area edges and adjacent CozyNotes windows while dragging.
- Added Windows resize snapping so touching notes can match width, height, or both while preserving the stationary note.
- Added DPI-aware capture and release thresholds, deterministic target selection, and support for folded notes.
- Excluded hidden, minimized, cloaked, unrelated, and library windows from snapping targets.
- Preserved snapped visible edges when restoring notes after Windows native frame insets settle.
- Disabled note maximization on Windows so native edge gestures do not resize notes unexpectedly.
- Added geometry, resize, native message, lifecycle, and placement regression coverage.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.2.2_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS Apple Silicon:** Open `CozyNotes_0.2.2_macos_aarch64.dmg` and drag CozyNotes to Applications.
- **macOS Intel:** Open `CozyNotes_0.2.2_macos_x64.dmg` and drag CozyNotes to Applications.
- **Linux x64:** Use `CozyNotes_0.2.2_linux_x64.deb` with your package manager, or make `CozyNotes_0.2.2_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Windows and macOS builds are unsigned, and macOS builds are not notarized. macOS may require approval in Privacy & Security.

Use `SHA256SUMS.txt` to verify downloaded files.
