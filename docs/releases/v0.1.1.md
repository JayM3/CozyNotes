# CozyNotes v0.1.1

A little home for your notes, now with downloads for Windows, macOS, and Linux.

## What's included

- System tray access to notes, the main menu, and Exit CozyNotes.
- A remembered Run in background preference in Settings.
- Warm, Night, and System appearance settings shared across open windows.
- Bulk note selection, Move to Trash, and confirmed permanent deletion from Trash.
- Rich text, lists, checklists, library search, paper colors, and local autosave.

## Downloads

| Platform | File |
| --- | --- |
| Windows x64, run directly | `Cozynote.exe` |
| Windows x64 installer | `CozyNotes_0.1.1_windows_x64_setup.exe` |
| macOS Apple Silicon | `CozyNotes_0.1.1_macos_aarch64.dmg` |
| macOS Intel | `CozyNotes_0.1.1_macos_x64.dmg` |
| Linux x64 AppImage | `CozyNotes_0.1.1_linux_x64.AppImage` |
| Debian/Ubuntu x64 | `CozyNotes_0.1.1_linux_x64.deb` |

The Windows standalone executable requires Microsoft WebView2 Runtime. The Windows
installer can install the runtime when needed. The app always stores notes in its
per-user data directory, including when you run the standalone executable.

On macOS, open the DMG and drag CozyNotes to Applications. These builds are not
signed with an Apple Developer ID or notarized; Gatekeeper may block them. macOS
users who require a signed and notarized app should wait for a later release.

The Linux downloads are built on Ubuntu 22.04 and require WebKitGTK 4.1 and a
compatible desktop environment. The Debian package declares runtime dependencies.
For AppImage, mark the file executable before opening it; systems without FUSE can
try the AppImage's `--appimage-extract-and-run` option.

`SHA256SUMS.txt` lists SHA-256 hashes for all six downloads.

## Release status

This is an early release. Windows and macOS downloads do not have publisher
signatures. Native builds and automated checks run on GitHub Actions for each
target. Windows has received local desktop testing; macOS and Linux have not yet
received equivalent native interaction and installer testing.

Your notes stay local, and no account is required. Automatic in-app updates,
attachments, user-facing backup/restore, and exports are not included.
