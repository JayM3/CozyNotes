# CozyNotes v0.1.5

## Changelog

- Added image paste and drag-and-drop import for notes.
- Added image file selection from the note toolbar.
- Added persistent local image storage with support for PNG, JPEG, GIF, WebP, and BMP files up to 25 MB.
- Added image zoom controls and unavailable-image states in the editor.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.1.5_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS:** Open the matching `.dmg` file and drag CozyNotes to Applications. The builds are unsigned and not notarized, so macOS may require approval in Privacy & Security.
- **Linux x64:** Use `CozyNotes_0.1.5_linux_x64.deb` with your package manager, or make `CozyNotes_0.1.5_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Use `SHA256SUMS.txt` to verify downloaded files.
