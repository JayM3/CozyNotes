# CozyNotes v0.2.4

## Changelog

- Double-click a note's left or right border to reset its width to the default 305 logical pixels, or its top or bottom border to reset its height to the default 385 logical pixels.
- Double-click a corner to reset both dimensions. The opposite edges stay anchored, and the default size follows display scaling.
- Reset sizes are remembered with the note's window arrangement. Folded notes retain their folded size.
- Windows x64 is the current supported platform. macOS and Linux updates are on hold.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.4_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
