# CozyNotes v0.2.1

## Changelog

- New note windows open at a compact 305 by 385 size, with a matching minimum width and saved window placement support.
- Added a resizable note toolbar that remembers its preferred height for each note and leaves room for editing in shorter windows.
- The toolbar resize handle supports dragging, keyboard arrows, Home and End, and double-clicking to reset its height.
- Reorganized formatting controls into two rows and added a New note button directly to the note toolbar.
- Fixed Windows frameless note sizing so the saved dimensions are applied after the window's native frame settles.
- Added regression coverage for toolbar preferences, resizing limits, and default note dimensions when fitting windows to a monitor.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.2.1_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS Apple Silicon:** Open `CozyNotes_0.2.1_macos_aarch64.dmg` and drag CozyNotes to Applications.
- **macOS Intel:** Open `CozyNotes_0.2.1_macos_x64.dmg` and drag CozyNotes to Applications.
- **Linux x64:** Use `CozyNotes_0.2.1_linux_x64.deb` with your package manager, or make `CozyNotes_0.2.1_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Windows and macOS builds are unsigned, and macOS builds are not notarized. macOS may require approval in Privacy & Security.

Use `SHA256SUMS.txt` to verify downloaded files.
