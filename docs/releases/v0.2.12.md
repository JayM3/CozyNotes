# CozyNotes v0.2.12

## Changes

- Check GitHub for updates automatically when CozyNotes starts and every three hours while it is running.
- Show **Update available** beside Settings when a newer release is found.
- Keep the detected update available while moving between Notes, Trash, and Settings, with a one-click install action in Settings.
- Retry overdue checks after sleep or a temporary connection failure without interrupting note taking.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.12_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
