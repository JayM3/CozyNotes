# CozyNotes v0.2.6

## Changelog

- Draw directly on a note alongside editable text with a Windows pen. Drawing tools include four colors, three widths, stroke erasing, undo and redo, and optional mouse drawing.
- Ink stays at its paper coordinates when text reflows or the window resizes, and moves with the note as it scrolls. Fingers scroll; ordinary mouse input edits text.
- Save note-level ink with autosave, note history, duplication, Trash, and restoration. Drawing descriptions are searchable, and existing inline ink drawings remain editable.
- Finish in-progress strokes when saving, closing, folding, or switching away from a note.
- Windows x64 is the only supported platform for this release. macOS and Linux packages are not provided.

## Install

- **Windows x64 standalone:** Run `Cozynote.exe` directly. WebView2 Runtime must be installed.
- **Windows x64 installer:** Run `CozyNotes_0.2.6_windows_x64_setup.exe`. The installer can install WebView2 Runtime when needed.

Existing installations can check for this release in Settings and install the signed update. The signed Windows updater and its signature are included in the release assets.

Windows downloads do not have a publisher certificate. Use `SHA256SUMS.txt` to verify downloaded files.
