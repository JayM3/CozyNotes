# CozyNotes v0.1.2

## Changelog

- Added editable note titles in the note header.
- Saved titles are searchable and remain separate from note body content.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.1.2_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS:** Open the matching `.dmg` file and drag CozyNotes to Applications. The builds are unsigned and not notarized, so macOS may require approval in Privacy & Security.
- **Linux x64:** Use `CozyNotes_0.1.2_linux_x64.deb` with your package manager, or make `CozyNotes_0.1.2_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Use `SHA256SUMS.txt` to verify downloaded files.
