# CozyNotes v0.1.4

## Changelog

- Added keep-on-top behavior for note windows.
- Improved note window scrolling and save status announcements.
- Added the app version to the library navigation rail.

## Install

Download the matching file from the release assets.

- **Windows x64:** Run `Cozynote.exe` directly, or use `CozyNotes_0.1.4_windows_x64_setup.exe`. The standalone app requires WebView2; the installer can install it when needed.
- **macOS:** Open the matching `.dmg` file and drag CozyNotes to Applications. The builds are unsigned and not notarized, so macOS may require approval in Privacy & Security.
- **Linux x64:** Use `CozyNotes_0.1.4_linux_x64.deb` with your package manager, or make `CozyNotes_0.1.4_linux_x64.AppImage` executable before opening it. The Linux builds require WebKitGTK 4.1.

Use `SHA256SUMS.txt` to verify downloaded files.
